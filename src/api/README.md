# ELTA API 버전 관리

ELTA 백엔드 애플리케이션은 REST API의 버전 관리를 위해 URL 경로 방식을 사용합니다.

## 버전 관리 방식

- **v1**: 최초 릴리스된 API 버전으로, 기존의 모든 엔드포인트가 포함됩니다.
- **v2**: 새로운 기능을 포함한 개선된 API 버전입니다.

## 각 버전의 특징

### v1 API

- 경로 프리픽스: `/v1`
- 상태: 유지보수 모드 (bugfix만 적용)
- 주요 특징: 초기 출시 버전의 기본 기능 제공

### v2 API

- 경로 프리픽스: `/v2`
- 상태: 활발한 개발 중
- 주요 특징: 
  - 향상된 성능
  - 개선된 오류 처리
  - 새로운 비즈니스 요구사항 구현
  - 더 일관된 응답 구조

## 버전별 폴더 구조

```
src/api/
├── v1/                        # v1 API 구현
│   ├── admin/                 # 관리자 관련 API
│   ├── auth/                  # 인증 관련 API
│   ├── broadcast/             # 브로드캐스트 관련 API
│   ├── delivery/              # 배송 관련 API
│   └── ...
├── v2/                        # v2 API 구현
│   ├── health/                # 건강 체크 API
│   └── ...                    # 추가 API 모듈
├── v1-api.module.ts           # v1 API 전체 모듈
├── v2-api.module.ts           # v2 API 전체 모듈
└── README.md                  # 이 파일
```

## API 버전 선택 가이드라인

- 신규 프로젝트는 최신 API 버전(v2)을 사용하는 것을 권장합니다.
- 기존 프로젝트는 호환성을 위해 사용 중인 API 버전을 계속 사용할 수 있습니다.
- v1 API는 장기 지원을 보장하지만, 새로운 기능은 v2 API에만 추가됩니다.

## API 버전 마이그레이션

v1에서 v2로 마이그레이션하는 경우 다음 사항을 참고하세요:

1. 응답 구조의 변화가 있을 수 있으므로 클라이언트 코드를 적절히 수정해야 합니다.
2. 새로운 인증 메커니즘이 도입되었을 수 있으므로 인증 관련 코드를 업데이트해야 할 수 있습니다.
3. 일부 엔드포인트가 통합되거나 분리되었을 수 있으므로 API 문서를 참고하세요.
